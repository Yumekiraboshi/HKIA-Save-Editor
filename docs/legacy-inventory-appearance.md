# Historical inventory appearance projection (3.0.1)

Native tags 1 (FurnitureUniqueDataDeprecated), 2 (FlowerUniqueDataDeprecated) and 5 (WandUniqueDataDeprecatedV75) retain the original GUID-based fields. Previously the editor only normalized these fields in its shared effective-value path when the row met unique quantity/edit policy. A reference-locked or otherwise non-editable original could therefore display the neutral template, despite known appearance.

The display-only snapshot now first honors the existing effective edited state, then resolves verified historical fields independently of edit eligibility, only for V301. The existing GUID-to-index flower and furniture tables remain authoritative; no inferred GUIDs. Furniture retains its normal UiIcon and known material metadata. The old wand source GUID is resolved through the complete native definition GUID crosswalk (all known item definitions, not just allowed creation ingredients), and the all-zero GUID maps to the native magic source. Unknown GUIDs remain opaque. The native nested source type is retained, but its appearance fields are not expanded for the fallback because native TryGetSubIcon reads only the source GUID, not copied source appearance.
