# Original furniture base material / shader source — v3.0.1

The extractor `scripts/extract-furniture-base-material-source.py` reuses the original static scene crosswalk, exact serialized Material property sheet fields and existing DXBC container validation. Each Renderer Material reference is resolved by native file ID and signed PathID, including external CAB references. All 11 base materials and 13 non-null distinct texture objects across the four sample models were extracted with their serialized property values, keywords, UV transform, full original mip chains, sampler settings and hashes. All non-null texture PPtrs resolve; the sole unresolved shader program is the non-customizable Antique Lamps Extra material (definitions CAB-46b8f8fe122147493b3113f7c1c8cd0f PathID -6681258383375895387). Its existence was independently checked in the original definitions object table (class 48). The extractor records that dependency as unresolved rather than substituting the furniture shader. The exact 13 texture streams total 3495540 bytes, kept only in local offline staging.

For the COLO26 rug (32709745), the exact default material is CAB-af62d986c5c317c0971b093103ecb65e:-432121064892149366. _BaseMap points to BlankPattern_Masked (external CAB-f36a12e51bf5e27445cb87735bf01b09, PathID 1092995113458411186), 2x2 RGBA32 with 2 mips, not an arbitrary white texture. _BumpMap and _MetallicGlossMap are the local BC3 512x512 textures Decor_COLO26_Rug_N and Decor_COLO26_Rug_X, both native color-space field 0. The default _PatternMap points to Decor_Pattern_HelloKitty_Var3_C with texture scale (10,10), not one of the six customization choices; the original runtime material application is separate. _PatternNormalMap and _Surface_EffectMap are explicit null pointers. All base Material properties are retained rather than applying the UI swatch. All six customization patterns were extracted in the separate material source PR; no pre-rendered combinations.

These are container counts, not 145 unique material appearances. Only names, parameters, segment/program hashes and ranges are committed; original compiled code remains offline. This identifies the actual shader family and establishes the data path for browser translation; it does not yet reproduce shader calculations or camera, lighting, native framebuffer or inventory icon parity.
