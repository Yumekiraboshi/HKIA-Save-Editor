All 11 base materials and 13 non-null distinct texture objects across the four sample models were extracted with their serialized property values, keywords, UV transform, full original mip chains, sampler settings and hashes. ## Browser texture upload primitive

`src/native-texture-upload.ts` verifies the original mip layout, full SHA-256 and each mip hash before uploading RGBA32, BC1 or BC3 source bytes to WebGL2. Color-space field 0/1 is retained as linear/sRGB; compressed sRGB uses the corresponding S3TC extension rather than decoding the RGB channels as linear. BC1 alpha mode is a required caller choice, not inferred from the optional alpha metadata. Original repeat/clamp/mirror modes, min/mag filtering, mip bounds and anisotropy are set when supported. Nonzero mip bias, mirror-once and unavailable GPU extensions refuse instead of silently altering sampling. Failure deletes the allocated GPU texture; success transfers ownership to the caller. Local TypeScript compile and byte/hash validation against all 19 extracted original base/pattern payloads (182 mip levels, 4544196 bytes) succeeded. The local Chromium GPU initialization failed, so actual WebGL upload / framebuffer sampling is NOT yet verified. This helper is not wired to the production editor and no binary source texture streams are shipped. Browser shader translation, BC1 semantics for the chosen shader path, and camera/lighting are still pending.
