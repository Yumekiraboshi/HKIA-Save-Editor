# Original furniture lighting arithmetic — v3.0.1

The same hash-pinned keyword-free ForwardLit pixel program cde2be6de0bbdfa6c9b3219fa302a61c5812a1efb6cbaf1e17868dd760b3e0e4 from the original Steam CustomLitFurniture shader is translated through its remaining lighting arithmetic in `src/furniture-lighting-v3.0.1.ts`. This display-only helper has no default light or scene selection. It accepts explicit shader-space albedo, roughness, metallic, occlusion, normal and view direction, native direct light, interpolated ambient, screen-occlusion sample, two reflection cube samples, reflection intensity/blend/strength, emission and fog inputs. The native code's dielectric reflectivity, roughness floor, environment mip formula, Fresnel fourth power, specular denominator and clamp, ambient/occlusion multiplication, emission mask and fog blend are retained. Reflection direction and mip are exposed for actual texture sampling.

The existing restricted native token evaluator was made reusable and extended only for the required dot/divide/reciprocal-square-root/return operations. It compares against the exact original token blocks 472–579, 593–742, 779–797 and 798–1094 (exclusive ends), supplying synthetic sample values at the actual sampling boundaries instead of executing texture fetches. All 128 independently generated fixtures matched the compiled TS helper locally; maximum absolute discrepancy was 2.85e-14 in double precision. This is arithmetic agreement, not bitwise GPU or final game-image parity. The previous 224 surface fixtures regenerated to their unchanged SHA-256. Reproduce via `scripts/extract-furniture-shader-bindings.py ... --lighting-vectors data/furniture-lighting-vectors-v3.0.1.json`; hash of fixture file 350bd4449929c3fddfd72def1a97872aaed63c6b25dd6c440231b29e5112da92.

This is the low-keyword/no-shadow program only, not proof that the actual furniture preview selects it. Native scene light settings depend on LightingRegion / PlayerLightingManager, time and weather. Actual interior variant, shadow and reflection map sampling, ambient vertex interpolation, postprocessing and color conversion still require evidence. No finished furniture image is published, no source asset bundles or native compiled shader are committed, and no save logic is changed.
