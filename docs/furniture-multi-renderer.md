The actual original normal, base, combo, pattern and both reflection maps were uploaded with original mips. The local harness used equivalent GLES calls, explicit orthographic diagnostic camera, synthetic illumination, explicit BC1 RGB interpretation, face order 0..5, no native shadow/postprocessing, no claim of Unity color conversion or game icon parity. Native sampler anisotropy was not applied by this equivalent local harness. This is not a verification of the newly committed browser transport itself.

The new WebGL2 multi-renderer path reuses the original material resolver, transform chain, shared verified geometry/texture/cube transport and shader. It preflights all meshes and shader features and resolves all source assets before the first draw; caller discards framebuffer on failure. The shader currently refuses the stand/lamp authored rim-light/other-shader variants rather than dropping their parts. The chair and existing rug can use this keyword-free diagnostic. It is not yet enabled in production inventory. The added test enumerates all 1394 source combinations and the six rug variants without generating images.
