# Remaining native wand single-mip source sprites (Steam 3.0.1)

The full native definition census (SHA-256 `ba9f3f97d1598a6923d2f804a704ab356c33866aa2d5f03bf11003735419e9e0`) resolves 12,163 Item IDs to 5,020 distinct local UiIcon Sprite PathIDs. The pinned candidate source pack covers 3,150 distinct sprites. Subtract those and the seven distinct sprites already covered by the five non-square sources and two shared dynamic templates. The remainder is 1,863 square Sprite identities for 3,199 definitions. Original GlobalUIAtlas SHA-256 `04c1f4c191b0a821a0bbcb15e67a75bec85cf343a0b2e875ee8e525e1e8dfc7b`; all remainder sprites have centered pivots and zero borders, with source-verified atlas or standalone geometry and render keys.

1,816 of the remainder sprites (3,152 definitions) have a single mip, bilinear filtering and sRGB color space. Decode each original RGB24/RGBA32/BC3 texture, sample its actual Sprite trim on the same 34×34 output pixel centers and 84px editor content grid as the previous candidate source pack (0.4 scale, −0.25/+0.25 offset, no rotation). Convert original RGB samples to linear space before bilinear interpolation and return to sRGB, retain linear alpha in a separate opaque RGB plane. Four standalone 256px Sprite rects extend 0.000002325 texels beyond the texture boundary due to stored float precision; validate within 0.001 texel and use original clamp sampling, not altered geometry. Original sample bytes are quantized to 8-bit and packed as four lossless RGB+alpha WebP sheets; each decoded sheet matched its original sample array exactly. File sizes: 920244, 925834, 936918, 147336 bytes. Total image bytes 2,930,332. Per-source Sprite and Texture PathIDs, render key, sample hash, sheet hash and exact Item ID mapping are recorded in the pinned 431,446-byte manifest (SHA-256 `7b4834de7a2dbc86bb1fb7592c84da17630605b76a01c4f396f833da616d94ac`). All five Git blob hashes were independently checked against local generated bytes.

The remaining 47 Sprite identities each correspond to one definition and use 512×512 BC1/DXT1 original textures with ten mip levels. They are explicitly excluded from this pack; source mip selection and actual framebuffer geometry require separate verification. Existing guarded and original-cell routes remain available, with the original fallback limitations. No new completed wand variants, game binaries or personal saves are published. For the newly sampled definition IDs, reuse existing bounded cache, normalized sample placement and all nine shape transforms. Guarded/placeholder/shared-template/candidate source paths take precedence; the new pack precedes normalized cells. This is read-only artwork, not expanded recipe or edit eligibility. The source extraction and lossless decoded sheet comparisons succeeded locally; CI and browser tests check exact route binding, original inventory source agreement, asset hashes, independent manifest failure and no-cell rendering. Actual game framebuffer equivalence remains unverified.
