# Multi-model native source pack smoke

Run on a local machine with the repository's installed dependencies, Chromium and an original-source pack staged using the existing assembler/stager:

```sh
node scripts/furniture-pack-native-smoke.mjs \
  --pack /path/to/staged-pack \
  --manifest-sha256 <independently-recorded-sources.json-digest> \
  --manifest-bytes <independently-recorded-byte-length> \
  --item 302413286 --limit 64 --size 160
```

Use --offset and --limit (1–256 cases per invocation) for bounded scans; omit --item to scan every model in the pack. Use --defaults-only to check exactly one default sentinel tuple per staged model, e.g. --defaults-only --limit 76 for the recovered 76-model pack. The report records the case mode and clear-relative pixel counts. CHROME_BIN overrides executable selection. Input path must be a staged directory, not a ZIP. Manifest pin must come from independently reviewed extraction/staging evidence, not the untrusted downloaded manifest itself. Staged files stay local: Playwright fulfils same-origin requests from the allowlisted directory, checks SHA-256 and exact length before sending bytes to the browser, rejects path escape, and the existing browser pack reader revalidates the manifest and individual payloads. No remote server, original binary publication or pre-generated production artwork. Do not publish the local source directory automatically.

The original 3.0.1 catalog contains 649 customizable models, 1089 assigned slots and 26274 slot choices (including source defaults once per slot). Enumerating each model's single all-default tuple, then changing one slot at a time to each allowed nondefault index, yields 25834 diagnostic cases across the full catalog, rather than a Cartesian product. The four previously committed sample model identities yield 108 cases; side table 302413286 yields 11. These counts describe the schedule, not render readiness. The actual run is restricted to model IDs present in the pinned pack and can still fail on absent pattern data, unsupported shader/geometry or payload validation.

The smoke invokes the canonical source-pack fetcher, authored camera, static bounds fit and raw framebuffer renderer for each case. All draw errors are recorded by case and summarized; successful raw frames retain alpha/RGB counts and SHA-256. No PNG export or forced alpha, no rejection merely because two source appearances may legitimately look identical. Synthetic scene lighting, cube orientation, BC1 RGB choice, identity root, zero clear and native camera relative transforms are explicit diagnostics; the report is not proof of Unity scene/output parity. Exits nonzero for any failed cases or route failures, while retaining the JSON report in stdout. No actual live volume or LDR pipeline activation by this script.

## Actual original-source canonical execution

Recovered 76-model manifest SHA-256 cba1d24db2d89b93f1c3155d8d4777e3eba62b13589c40fac7e09cd085e4839a (784788 bytes), renderer source commit 8f7bcdb57d3db8e9d1765395c048ff398b465ffb (PR #277). Transferred 31 public source/catalog/script files via the GitHub connector; each Git blob SHA-1 matched the returned file identity. Unmodified TypeScript compiled with strict type checking. Node executed the actual fetchFurnitureSourcePack with an injected local file fetch, validated all 76 source/material/camera/bounds plans and read all 205 unique payloads (118334376 bytes) through the canonical SHA-256-verifying reader. The isolated Chromium WebGL2 run executed the compiled, unchanged fitFurnitureMultiStaticBounds and renderFurnitureDiagnosticFrame implementations for all 76 default tuples, using the original source metadata and verified local payload bytes. Because navigation to a loopback URL is blocked by the execution environment, the browser harness used a blank document, a local byte reader, and a local SHA-256 test adapter (native WebCrypto was unavailable in that document; verified all actual source payloads independently in Node). No real HTTP browser transport was exercised. No external network/asset upload, no source modifications, no private save data. The same explicit diagnostic scene parameters as the committed smoke were used. Results: 76/76 successful, 76 distinct raw frame digests, 132 mesh renderer instances, 135462 visible pixels total; item 302413286 retained 160 zero-alpha RGB pixels, and three shelves and the banner retained partial alpha. This is actual canonical GPU execution, not full native scene parity: the diagnostic CCW/front-face behavior, synthetic lighting, cube orientation and final grading remain separate issues. No full variant coverage, production UI or Pages claim. The earlier 118-model pack remains absent; counts cannot be added without deduplication.
