# LDR preview GPU diagnostic

The WebGL2 path uses the existing source-derived flattened LUT sampling helper, explicit exposure and vignette uniforms and the three previously identified output conversions. It uploads RGBA8 forward readback and the existing LUT atlas, processes the frame and its corresponding clear in two color attachments in one draw, and reads back both. It retains the original forward frame and requires exact alpha preservation, including pixels with zero alpha but changed RGB. There is no alpha repair or automatic profile selection. User LUT, HDR, bloom, native target resolution and actual final-pass selection remain unsupported by this GPU path; the CPU reference remains unchanged. No source asset or production UI activation.

Run `node scripts/furniture-ldr-gpu-smoke.mjs` with the existing browser diagnostic dependencies. It compares GPU and CPU results for the three output modes, vignette on/off and identity/default diagnostic LUTs, including alpha and hidden coverage. Local strict TypeScript compilation of the GPU module against matching interface shapes succeeded; the current container's Chromium could not create even a blank WebGL2 context. Actual browser execution of this new path is not yet verified; no real furniture rendering, performance or game screenshot parity is claimed.
