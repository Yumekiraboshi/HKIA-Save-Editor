## Shared verified atlas fallback binding

The four CSS consumers (InventoryAtlasSprite, DyeSprite, DynamicArtSprite and DynamicFlowerSprite) now use a single reactive binding to the existing verified native inventory sheet request. Previously the ordinary native atlas path verified bytes, but dye, dynamic and flower state/static preview fallbacks could install the raw network URL. Native sheet fallback remains absent until the exact sheet has been verified and decoded; a replaced source never exposes its previous cell. Collection ZIP cells and verified growth-sheet cells retain their existing local URLs. The dynamic and ordinary atlas paths keep viewport gating; original images retain priority over any fallback. This changes no native selection rules, colors, source art or save mutations. The shared request tests cover recovery, cancellation and bounds; the UI binding audit covers all four consumers. Actual game/Pages framebuffer comparison remains separate.
