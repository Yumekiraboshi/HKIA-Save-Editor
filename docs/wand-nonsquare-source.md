The common sample placement code uses the same square grid only as the output sample container, not as the Sprite's aspect. One 170×68 opaque RGB+alpha WebP (6,226 bytes) provides the five source tiles. Its SHA-256 and lossless decoded RGB are pinned; samples have 8-bit quantization, not a Unity framebuffer capture. No finished wand variants or complete game binaries are distributed. Existing ordinary sampled pack and fallback remain unchanged.
