# HKIA Save Editor

Browser-local HKIA collection save editor built with **Rust/WASM + TypeScript + Svelte + Web Workers**. No save files are uploaded.

## Development

This repository contains the publicly distributable source and GitHub Pages site. For local development, install Node.js 22+ and a Rust toolchain with `wasm32-unknown-unknown`, then run `npm ci`, `npm run build:wasm`, and `npm run dev`.

**Status:** implementation in progress. Do not use an edited save without retaining an untouched backup. Support is limited to verified save versions and formats; entitlement, quests and other game systems are not changed automatically.

Independent, unofficial tool. Not affiliated with Sunblink, Sanrio, or Apple Arcade.
